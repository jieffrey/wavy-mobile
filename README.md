# Wavy Mobile

App mobile Wavy khusus **customer** (beli tiket konser, tiket QR, riwayat order).
Expo SDK 58 + expo-router + TypeScript, dijalankan lewat **Expo Go** (tanpa dev build).

Backend: `wavy-backend` (`/api/v1`, port 1420). Panduan jalan lengkap menyusul di branch `feat/foundation`.

```bash
npm install
npx expo start
```
